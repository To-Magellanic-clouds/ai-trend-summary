这个项目起源于我想做一个下面ai发展报告的功能:

ai突破进展周报,关注本周ai在以下方面取得的最具有突破性的进展:
- ai模型能力
	- 语言和推理能力
	- 多模态能力
- ai商业化
	- 出圈的产品形态
	- 高额盈利的案例
- ai底层技术
	- 最热/最具突破性论文
- ai投资
	- ai公司融资情况
- ai政策
	- 对行业影响最大的政策

然后我发现这是一个很通用的工作流,可以用来做任何领域的信息总结,所以我把它抽象成了一个通用的工作流,可以用来做任何领域的总结。
最重要的功能是基于用户的需求筛选信息并生成摘要,使用大模型进行信息总结,并且支持用户自定义摘要的格式和内容
整体工作流如下:
1. 信息收集
2. 信息预处理
3. 信息分析
   - 关键词识别
   - 标签归类
   - 关系抽取
4. 基于用户定义的筛选方法筛选整合信息
   - 用户定义筛选的维度有
     - 文章来源
     - 文章类型
     - 关键词
     - 时间范围
     - 领域
5. 信息总结
6. 信息输出

## 最小化产品描述
爬取Huggingface上关于ai的博客,并使用大模型进行关键词识别与归类,临时测试的结果输出到result/Huggingface/Blog/Trending目录下,真正的结果还是存到云服务器的MongoDB和postgres等数据库中
- MongoDB 存储非结构化文本和二进制内容，支持动态 Schema
- PostgreSQL 存储结构化元数据（如文章 ID、来源、分类标签、关键词、关系、处理状态）
- 向量化存储使用向量数据库（如 Pinecone、Weaviate）存储文章内容的向量表示，支持高效的相似度搜索
使用langchain构造工作流,增强各个环节的功能的可扩展性
目前只做ai技术(比如基础模型,MCP,RAG,Agent)/ai产品(包括各大厂商推出的使用的大模型技术的产品的以及介绍)领域的信息收集和分析,后续会扩展到其他领域

	- 深度定制一些通用的mcp tool/sdk, 做到例如
		- 抓取huggingface发布的模型
		- producthunt的热门产品信息
		- 抓取twitter用户的发帖
- ai抓取框架
	- [**Crawl4AI**](https://docs.crawl4ai.com/)：是基于 Python 开发的开源智能爬虫框架。其渲染层深度集成了 [[Playwright]]（默认）和 [[Selenium]]，支持无头 / 有头模式，还内置了反反爬机制。它采用分层设计，调度层基于 asyncio 的自适应并发调度器，支持动态调整爬取并发数；提取层创新性引入 LLM 驱动的智能提取引擎，可通过自然语言指令生成结构化数据；输出层原生支持 Markdown/JSON/CSV 格式输出，特别适配 LLM 的上下文输入要求。
	- **WebCrawlAI**：是一个由 AI 驱动的网络爬取工具，可爬取给定网站上的任何类型的数据，并只返回需要的信息。它用到了 Selenium 来自动化网页浏览和处理动态内容，还结合了 BeautifulSoup、lxml 等用于解析和提取数据，利用谷歌生成式 AI 将 AI 功能集成到爬虫中，通过自动化数据提取流程，可处理动态更新的内容和需要输入验证码的网站，提供干净、结构化的数据。
	- **Firecrawl**：一个 “将任何网站转化为 LLM 就绪（LLM - ready）的干净 Markdown / 结构化数据” 的工具。它支持抓取单个 URL，也支持设定爬行深度和规则，对整个网站或特定路径下的页面进行爬取。虽然未明确提及集成 Selenium，但作为爬虫工具，在处理动态页面时，理论上可与 Selenium 结合使用，且其输出格式适合 RAG 等 LLM 应用场景，提供简单 API 接口，方便开发者集成到自己的应用程序中。
