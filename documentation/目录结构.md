整体项目结构
- src 源代码目录
  - infrastructure 基础设施层,包含与底层服务交互的代码
    - utils 一些通用的工具
      - db 数据库连接
- test 测试代码目录
- result 结果输出目录,该目录存放项目运行产生的结果文件，按来源和类型进行划分。
- documentation 文档目录
- .env 环境变量,主要用于加载配置
- pyproject.toml 项目依赖


文件命名规范
类文件：采用大驼峰命名法，如 OpenAIProvider。
函数文件：采用小写字母和下划线组合的命名法，如 get_provider。
配置文件：采用 config 作为前缀，如 config.py。
测试文件：采用被测试文件名称加上 Test 后缀，如 DirUtilTest.py。
其他规范
依赖管理：使用 pyproject.toml 文件管理项目依赖，使用uv工具做包管理。
文档说明：每个模块下建议包含 README.md 文件，说明模块功能、使用方法等信息。
环境配置：敏感信息（如 API 密钥）应通过环境变量或配置文件管理，避免硬编码在代码中。
